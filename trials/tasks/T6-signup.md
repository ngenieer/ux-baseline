# 과제 T6 — 회원가입 (도입 꾸러미 시험, 다른 모델)

쇼핑몰 회원가입 화면 한 장. 바닐라 HTML·CSS·JS(외부 라이브러리 없음), 서버 대신 스크립트 안의 가짜 응답.

- 입력: 아이디(중복 확인 버튼 — 가짜 지연 후 '사용 가능/이미 사용 중'), 비밀번호·비밀번호 확인(규칙 안내), 이름, 휴대전화, 이메일, 생년월일.
- 약관 동의: 전체 동의, 필수 약관 2개(내용 펼쳐 보기), 선택 마케팅 수신 동의.
- 제출하면 검증 오류를 보여 주고, 통과하면 가입 완료 화면으로 바뀐다.
- 산출물: 프로젝트 루트의 index.html, style.css, script.js.
