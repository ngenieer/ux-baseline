# 과제 T1 — 민원 신청 폼

주민센터 "주민등록 등본 우편 발급 신청" 화면 한 장을 만든다.

- 입력: 신청인 이름, 생년월일, 휴대전화 번호, 이메일(선택), 받을 주소(우편번호 찾기 버튼 + 기본 주소 + 상세 주소), 발급 부수(1~5부), 신분증 사본 첨부(파일, 최대 2개, jpg·png·pdf, 10MB 이하), 개인정보 수집·이용 동의(필수), 수령 알림 문자 받기(선택)
- 버튼: 신청하기
- 화면에 "제출했는데 오류가 있는 상태"를 함께 보여 준다: 이름이 비어 있고, 휴대전화 번호 형식이 틀렸다.
- 산출물: `index.html`, `style.css` (같은 디렉터리의 `tokens.css` 를 먼저 불러온다). 스크립트는 쓰지 않는다 — 상호작용이 필요한 부분은 HTML 주석으로 동작을 적는다.
