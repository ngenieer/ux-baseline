# 과제 T7 — 운영 대시보드 (도입 꾸러미 시험, 다른 모델)

사내 주문 운영 대시보드 한 장. 바닐라 HTML·CSS·JS(외부 라이브러리 없음), 가짜 데이터.

- 상단: 기간 선택(오늘·7일·30일), 새로 고침 버튼(가짜 지연 후 갱신, 갱신 시각 표시).
- 요약 지표 카드 4개(주문 수, 매출, 취소율, 평균 처리 시간)와 전 기간 대비 증감.
- 일별 주문 추이 막대 그래프(SVG 직접 그리기)와 같은 데이터의 표.
- 최근 주문 표: 정렬, 상태 필터(전체·처리 중·완료·취소), 10건씩 페이지 이동, 데이터 없음 상태.
- 데이터 불러오기 실패 상태(시연용 선택지로 재현).
- 산출물: 프로젝트 루트의 index.html, style.css, script.js.
