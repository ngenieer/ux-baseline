# 과제 T2 — 공지사항 목록

구청 누리집 "공지사항" 목록 화면 한 장을 만든다.

- 페이지 제목, 현재 위치 경로(홈 > 알림마당 > 공지사항)
- 검색: 검색 대상 선택(제목·내용·작성 부서), 검색어 입력, 검색 버튼
- 분류 탭 또는 필터: 전체·일반·채용·입찰 (현재 '전체')
- 목록: 번호, 분류, 제목, 작성 부서, 등록일, 첨부 여부, 조회수 — 10건. 상단 고정 공지 1건 포함, 새 글 표시 1건 포함
- 전체 건수 표시(총 237건), 페이지네이션(현재 3페이지, 전체 24페이지)
- 산출물: `index.html`, `style.css` (같은 디렉터리의 `tokens.css` 를 먼저 불러온다). 스크립트는 쓰지 않는다 — 상호작용은 HTML 주석으로 적는다.
