# 과제 T3 — 삭제 확인 대화상자와 결과 알림

"내 신청 내역" 화면에서 임시 저장한 신청서를 삭제하는 흐름을 한 장에 보여 준다.

- 신청 내역 카드 3개(신청서 이름, 상태 배지: 임시 저장·접수 완료·처리 중, 마지막 수정일, 이어서 작성하기·삭제 버튼). 임시 저장 카드만 삭제 가능
- 열린 상태의 삭제 확인 대화상자(무엇이 지워지는지, 되돌릴 수 없다는 안내, 취소·삭제 버튼, 닫기 버튼)
- 삭제 후 화면 하단에 나타나는 결과 알림("신청서를 삭제했습니다")
- 상단에 상태별 보기 탭(전체·임시 저장·접수 완료)
- 산출물: `index.html`, `style.css` (같은 디렉터리의 `tokens.css` 를 먼저 불러온다). 스크립트는 쓰지 않는다 — 상호작용은 HTML 주석으로 적는다.
