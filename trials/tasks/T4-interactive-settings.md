# 과제 T4 — 알림 설정 화면 (스크립트 포함)

구청 누리집 "내 알림 설정" 화면 한 장을 만든다. 이번에는 **스크립트를 써서 실제로 동작하게** 만든다(외부 라이브러리 없이 바닐라 JS).

- 상단 탭 3개: 알림 수신 · 수신 방법 · 자주 묻는 질문. 탭을 누르거나 키보드로 바꾸면 해당 패널이 보인다.
- 알림 수신 패널: 분야별 알림 켜기·끄기 스위치 4개(복지, 교통, 문화, 재난 문자 — 재난 문자는 끌 수 없다는 안내 포함), 저장 버튼.
- 수신 방법 패널: 문자·이메일·앱 푸시 중 고르기(복수 선택), 이메일 주소 입력, 저장 버튼.
- 자주 묻는 질문 패널: 질문 4개를 펼치고 접는 목록.
- 화면 아래 "모든 알림 해지" 버튼 → 확인 대화상자(무엇이 해지되는지, 취소·해지 버튼) → 해지하면 결과 알림("모든 알림을 해지했습니다").
- 저장하면 결과 알림("알림 설정을 저장했습니다").
- 산출물: `index.html`, `style.css`, `script.js` (같은 디렉터리의 `tokens.css` 를 먼저 불러온다).
