# KRDS 수집분 중 카테고리 미정 항목

현재 카테고리 목록(`schema/categories.yaml`)에 맞는 곳이 없어 룰 ID를 부여하지 않고 보류한 항목입니다.

출처: KRDS 디자인 스타일 — 형태(style_04), 아이콘(style_06), 엘리베이션(style_08). 수집일 2026-10-18.

## 처리 기록

- 2026-10-18: SHAPE 카테고리 신설(합의). 형태(반경)·엘리베이션·그림자·딤드 항목을 SHAPE-001~006 후보로 옮겼다.
- 아이콘은 카테고리를 만들지 않기로 했다. 아래 항목은 4단계에서 토큰(크기·두께)으로 정의하거나 기존 룰에 흡수한다.

## 아이콘 (토큰 또는 기존 룰로 흡수 예정)

- 시스템 아이콘은 SVG로 만들고, 같은 의미에는 서비스 전체에서 같은 아이콘을 쓴다. → COPY-004(일관된 식별)
- 기준 크기 24px, 사용 크기 16·20·24·32·40px(4 또는 8의 배수). → 아이콘 크기 토큰
- 24px 기준 선 두께 1.5~2px(표준형 1.6px), 같은 크기 아이콘은 한 가지 두께만. → 아이콘 두께 토큰
- 아이콘 색은 인접 색과 3:1 이상(고대비 모드 7:1). → COLOR-003, COLOR-009
- 텍스트와 함께 쓸 때 세로 중앙 정렬하고, 텍스트 크기에 맞춘 아이콘 크기만 쓴다. → 컴포넌트 규격(4단계)
